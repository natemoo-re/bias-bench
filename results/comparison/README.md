# Cross-model comparison

`callback-gaps.svg` / `callback-gaps.png` — White − Black and Men − Women
callback-rate gaps (percentage points) for all five screeners, with 95%
cluster-bootstrap CIs, plus the Bertrand & Mullainathan (2004) human-recruiter
reference point. Generated by `node compare-graphic.js` (requires
`results/*/stats.json` from `analyze.js` first).

Every model sits on the opposite side of zero from the human audit reference:
all five favor Black-associated names on binary interview decisions, while the
human audit found White-associated names received ~50% more callbacks. Gender
gaps are within noise everywhere.
