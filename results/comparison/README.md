# Cross-model comparison

`callback-gaps.svg` / `callback-gaps.png` — both panels: callback-rate gaps
(percentage points) for all five screeners with 95% cluster-bootstrap CIs,
plus the human-recruiter reference point.
`callback-gaps-race.svg`/`.png` and `callback-gaps-gender.svg`/`.png` isolate
the individual panels. Generated by `node compare-graphic.js` (requires
`results/*/stats.json` from `analyze.js` first). Axes read left to right:
White → Black and Male → Female, so dots right of zero favor Black-associated
(left panel) or female (right panel) names; the stats tables elsewhere use the
White − Black / Men − Women convention (opposite sign).

Every model sits on the opposite side of zero from the human audit reference:
all five favor Black-associated names on binary interview decisions, while the
human audit found White-associated names received ~50% more callbacks. Gender
gaps are within noise everywhere.
